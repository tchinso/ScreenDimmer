# ScreenDimmer

각 모니터 위에 검은색 필터를 씌워 화면 밝기를 조절하는 Windows 프로그램입니다. 모니터의 DDC/CI 기능이 없어도 사용할 수 있습니다. 필터 방식이므로 `100% 어둡기`를 켜도 LCD 등의 백라이트는 계속 켜져 있을 수 있습니다.

## 사용법

- 모니터별 슬라이더로 밝기를 5% 단위로 조절합니다. `100% 어둡기`는 모든 모니터에서 동시에 켤 수 없습니다.
- 슬라이더나 `100% 어둡기`를 직접 조작하면 **해당 모니터만** 자동 시간표에서 빠집니다. 해당 줄의 `자동(cfg)`를 다시 체크하면 그 모니터에 현재 시간표 값을 적용합니다. `모든 모니터 자동(cfg)` 버튼은 전부 자동으로 복귀시킵니다.
- 상단 `설정` 메뉴에서 `필터를 항상 최상위로 설정`과 `Windows 시작 시 자동 실행`을 켜거나 끕니다. 자동 실행을 켜면 현재 EXE를 `silent` 옵션과 함께 사용자별 Run 레지스트리와 시작 폴더 바로가기에 등록하고, Windows에서 비활성화된 해당 항목을 다시 활성화합니다. 로그인 후 창을 띄우지 않고 트레이에서 시작하며, 두 경로로 실행되어도 단일 인스턴스만 유지됩니다. 끄면 두 등록을 모두 제거합니다. 자동 실행은 Windows 로그인 후 이루어지며, EXE를 옮겼다면 새 위치에서 다시 켜야 합니다.
- 창을 최소화하면 시스템 트레이로 이동합니다.
- `ScreenDimmer.exe silent`로 실행하면 처음부터 창을 띄우지 않고 시스템 트레이로 이동합니다. `--silent`, `-silent`, `/silent`도 사용할 수 있습니다. 트레이 아이콘을 클릭하면 설정 창을 엽니다. 이미 실행 중일 때 `silent`로 다시 실행해도 창이 열리지 않으며, 옵션 없이 다시 실행하면 기존 창을 엽니다.

## 자동 시간표

EXE와 같은 폴더의 `brightness.cfg`에 `19:00-21:00 = 65` 형식으로 한 줄에 규칙 하나씩 적습니다. 먼저 일치한 규칙이 적용됩니다. 파일이 없으면 EXE에 포함된 기본 시간표를 사용하므로 `dist/ScreenDimmer.exe` 하나만으로도 실행할 수 있습니다. 시간표 파일을 수정한 뒤에는 프로그램을 다시 시작합니다.

## 빌드

Windows용 `x86_64-w64-mingw32-gcc`와 `x86_64-w64-mingw32-windres`가 PATH에 있으면 PowerShell에서 `./build.ps1`을 실행합니다. 아이콘을 포함한 64비트 단일 실행 파일을 `dist/ScreenDimmer.exe`에 생성합니다.
